# BPCSStegoApp

Bu proje, **BPCS (Bit-Plane Complexity Segmentation)** algoritmasını kullanarak **görsel veri (BMP, PNG)** içerisine gizli mesajları daha yüksek kapasiteyle gömmeyi ve çıkarmayı sağlayan bir **Windows Forms uygulamasıdır**.

## 🚀 Özellikler

- 📷 Renkli görüntülere (BMP, PNG) yüksek kapasiteli mesaj gömme  
- 🔍 Gömülü mesajın görüntüden çıkarılması  
- 📊 Bit düzeyinde karmaşıklık analizi  
- 👨‍💻 Basit, sezgisel ve kullanıcı dostu arayüz

## 📌 BPCS Nedir?

BPCS algoritması, insan gözünün fark edemeyeceği yüksek frekanslı alanlara (karmaşık bit düzlemlerine) bilgi gizler. Bu sayede:

- **Daha fazla veri** gömülebilir.
- **Görsel kalite korunur.**

## 🧠 Kullanım

1. `TextBox` alanına gömmek istediğiniz mesajı yazın.  
2. `mesajı göm` butonuna tıklayarak bir BMP/PNG dosyası seçin.  
3. Mesaj otomatik olarak seçilen görsele gömülür ve yeni dosya `"output_bpcs.png"` şeklinde kaydedilir.  
4. ` mesajı çıkar` butonuna tıklayıp aynı veya başka bir BPCS ile işlenmiş görseli seçin.  
5. Mesaj, ekrandaki `TextBox`'ta görüntülenir.
